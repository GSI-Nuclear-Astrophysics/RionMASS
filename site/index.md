# RionMASS

Python, command-line and desktop software for storage-ring mass calibration.
Includes reference diagnostics, electronic-input covariance, custom reference
masses and saved-run replay.

```sh
python -m pip install 'RionMASS[gui]'
rionmass-gui
```

See the [repository](https://github.com/GSI-Nuclear-Astrophysics/RionMASS) for installation,
examples, documentation and citation information. Licensed under GPL-3.0-or-later.
